# TensorBoard 日志系统使用说明

## 📋 概述

这个系统会自动为每次训练运行创建带时间戳的独立文件夹，所有训练日志都存储在 `/home/qiaohongbo_26/sda/graduation/uav_irs-master/SAC/runs/` 目录中，方便您对比不同训练参数的效果。

## 🚀 使用方法

### 1. 开始训练

在PyCharm或命令行中运行训练脚本：

```bash
cd /home/qiaohongbo_26/sda/graduation/uav_irs-master/SAC
python train_SAC.py
```

运行后，系统会自动创建类似这样的日志目录：
```
20241119_143022/   # 2024年11月19日 14:30:22
```

您可以在训练过程中随时查看日志，不需要等训练完成。

### 2. 查看训练结果

#### 方法1：使用一键脚本（推荐）
```bash
# 查看所有训练记录对比
./run_tensorboard.sh --all

# 只查看最新一次训练结果
./run_tensorboard.sh --latest

# 查看指定的某个训练结果
./run_tensorboard.sh 20241119_143022
```

#### 方法2：手动启动TensorBoard
```bash
tensorboard --logdir=/home/qiaohongbo_26/sda/graduation/uav_irs-master/SAC/runs --host=0.0.0.0 --port=6006
```

打开浏览器访问：`http://localhost:6006`

## 📊 可以查看的数据

### 主要训练指标
- **奖励变化**：训练过程中的平均奖励、最高/最低奖励
- **损失函数**：Actor网络、Critic网络的训练损失
- **学习参数**：温度参数alpha的变化

### 系统性能指标
- **能量消耗**：UAV总能量消耗、地面节点充电量
- **公平性指标**：感知公平性、充电公平性
- **训练效率**：每个回合的训练时间、GPU内存使用情况

### 实际应用中可以：
- 🔍 **对比参数效果**：不同超参数设置下的训练曲线对比
- 📈 **监控训练过程**：实时查看损失函数是否收敛
- ⚠️ **发现问题**：检查能量消耗异常、训练时间过长等问题
- 📊 **优化模型**：根据公平性指标调整奖励函数权重

## 💡 实用建议

### 比较不同训练设置：
1. **第一次训练**：默认参数
2. **第二次训练**：修改学习率
3. **第三次训练**：调整批次大小

每次修改后运行训练，系统会自动创建新的时间戳目录，您可以在TensorBoard中轻松对比三条训练曲线。

### 常见问题：
- **Q**：训练中断后如何继续查看？
- **A**：重新运行TensorBoard即可，之前的日志一直保存着

- **Q**：磁盘空间不够了怎么办？
- **A**：删除runs/目录下不需要的旧文件夹即可

- **Q**：想自定义日志记录频率？
- **A**：在train_SAC.py中修改 `config.log_interval = 100` 参数
