# 代码实现 vs 论文 —— 差异说明（汇报用）

> 论文：*Efficient Layer-Granularity Unloading for LLMs in Edge Computing* (IEEE TMC 2026)
> 代码：`edge-unload-repro\`，场景据 2026-07-31 组会确定，全部验证通过。

## 一句话口径

**论文是「单服务器 · 单模型 · ski-rental 求解」；我们是「多服务器 · 多模型 · 任务路由 + 层卸载联合决策 · 留给 MARL 求解」。论文的成本模型被完整保留为每台服务器的内核，外面套了三层新东西。**

---

## 第①层：完整保留论文的什么

论文 §IV-A/B/C 的系统模型被**原样复用为每台服务器的内核**，并已精确验证：

- 层内存 $C_{k,s}=\sum_{i\le s}c_{k,i}$、加载延迟 $D_{m,k,s}$、QoS 最少常驻层 $\check i$、ski-rental 临界点 $B$；
- **退化验证**：单服务器 + 单模型 + 无传输无计算时，$\check i=3$、$B=30$、TABLE I 四成本 **100 / 140 / 185 / 225** 全部精确复现；
- **TABLE III 实测参数**：Qwen-7B 34 层 / 14728 MB（精确等于 Total 行）/ 满载加载 4769 ms（≈4760）。

## 第②层：我们新增了什么（论文里没有）

| # | 新增内容 | 论文 | 说明 |
|---|---|---|---|
| 1 | **M 台服务器 + 任务路由** $x_{j,m}$ | 单服务器 | 新增一整个决策维度，与层保留**双向耦合** |
| 1b | **服务器占用与排队** $\mathfrak b_m,\rho_m$ | 无 | 使负载均衡成为**稳定性必要条件**；卸载不再容量免费 |
| 2 | **K 个模型共享显存** $\sum_k C_{k,s}\le\bar C$ | 单模型 | 最主要的新增耦合；派生出两个可行性条件 |
| 3 | **无线传输时延** $T^{tx}$ | 无 | 香农速率 + 回程时延 $\delta_m$（越远越大） |
| 4 | **计算时延**（prefill + decode） | 无 | 各服务器算力/显存带宽不同；decode 为带宽受限 |
| 5 | **负载均衡** Jain 指数 | 无 | 作为目标的第三项（沿用毕设做法） |
| 6 | **异质双时标多智能体 MDP** | 无（用对偶求解） | 用户 1 个 agent（路由，每时隙）+ 服务器 M 个 agent（层保留，每 Δ 时隙），为接 GD-MAPPO 准备 |
| 7 | **放置变量** $y_{m,k}$（`hosts`） | 无 | 处理"最小常驻之和超显存"的不可行情形 |

### 四重张力（论文只有一重）

| | 论文 | 本工作 |
|---|---|---|
| 权衡维度 | 内存成本 ↔ 加载延迟 | 内存 ↔ 加载 ↔ **传输** ↔ **计算** ↔ **排队** ↔ **负载均衡** |
| 服务器选择 | — | 近但弱（$T^{tx}$ 小、$f$ 小）vs 远但强 |

实测量级（7B, 512→128 token）：传输 2\~80 ms、计算 1274\~3354 ms、加载 0 或 2135\~4135 ms。
三项同量级且方向相反（近端传输小但计算慢、云反之）⇒ **重任务云最优、轻任务近端最优**，路由非平凡。

## 第③层：我们改了论文的什么

| # | 改动 | 原因 |
|---|---|---|
| 1 | **$D_i$ 用 $\sum_{i'>i}$ 而非论文正文的 $\ge i$** | 论文正文笔误。状态 $s_i$ 已保留第 $i$ 层，只需重载其后的层；且只有 $>i$ 能复现 TABLE I 的成本。论文算法伪代码实际也隐含此定义。 |
| 2 | **封装成 DRL 环境（状态/动作/奖励）** | 论文本身**不用 DRL/MDP**（用 ski-rental + 拉格朗日对偶）。这是为迁移毕设方法做的翻译。 |
| 3 | **目标用求和而非平均** | 为了让环境的逐时隙奖励与目标函数**精确对应**（已断言累计奖励 $=-J$，误差 $<10^{-6}$）。报告用的平均时延另有接口。 |

- **DRL agent 与训练**。

## 汇报三句话

1. **论文的模型我完整复现了**，而且以 TABLE I 为 ground-truth 精确对齐（100/140/185/225），还发现并修正了正文一处笔误（$D_i$ 的求和下界）。
2. **新场景是论文的扩展**：多服务器路由 + 多模型共享显存 + 传输/计算时延 + 负载均衡，共 7 项论文没有的内容；模型已封装成多智能体环境，累计奖励与目标函数精确自洽。
3. **算法还没做**，符合当前阶段"只建模"的边界；下一步接毕设的扩散策略，并用 $\check i$ / $B$ 约束动作空间。

## 待师兄确认

1. **Δ 取多大**（长时标 epoch，默认 10 时隙 = 1 s）；以及**奖励分账**是否认可（用户背等待+传输+计算+公平，服务器背加载+显存）。
2. **可行性缺口**：$\sum_k C_{k,\check i}>\bar C$ 时需放置变量 $y_{m,k}$（已实现并有测试：8 GB 下正确报"无法服务 7B"）。
3. decode 用 max(算力, 显存带宽) 模型；更精细可加 KV-cache。
4. 排队为单服务器 FIFO；传输与计算流水。
5. 权重默认 ω=1（三项已归一化）。
