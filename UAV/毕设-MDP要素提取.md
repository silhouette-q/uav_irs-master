# 毕设 GD-MAPPO 的 MDP 要素提取

> 来源：乔竑博_毕设《基于生成式强化学习的通信、感知与充电一体化网络优化方法研究》第 3 章
> 用途：为"把毕设的扩散模型 DRL 迁移到边缘卸载问题"做准备，先把毕设原本的 MDP 四要素定清楚。
> 公式号对应毕设原文。

---

## 0. 框架总览

- **问题建模**：部分可观测马尔可夫博弈（POMG）。
- **训练/执行**：集中训练分布执行（CTDE）。Critic 训练期用全局状态；Actor 执行期只用局部观测。
- **算法**：GD-MAPPO = 生成式扩散策略网络替代高斯策略 + MAPPO + 奖励中心化。
- **智能体**：M 架同构无人机，m = {1,...,M}；每架 = 一个自治智能体。
- **实体**：无人机集群 + 1 个融合基站（固定 (x0,y0,H0)）+ N 个静态地面目标。
- **时间**：离散 T 个时隙，每隙时长 τ。
- **目标**：学习策略 π={π_1,...,π_M}，最大化折扣累计回报（式3-34）
  `J_m = E[ Σ_t γ^(t-1) r^m_t ]`, γ∈(0,1]。

---

## 1. 动作空间 A（式3-35~3-42）

单智能体每时隙 5 维**原始动作**（式3-35）：
`a^m_t = { l_m(t), ∂_m(t), p_m(t), β_m(t), ρ_m(t) }`

| 分量 | 物理含义 | 范围 | 约束号 |
|---|---|---|---|
| l_m(t) | 飞行距离 | [0, l^max] | C9 |
| ∂_m(t) | 飞行方向（角度） | [0, 2π) | C8 |
| p_mk(t) | 信道选择（二元，占用哪个子信道） | {0,1} | C6,C7,C12 |
| β_m(t) | 主/副波束功率分配系数（主=通信+充电，副=感知） | [0,1] | C10 |
| ρ_m(t) | 主波束内 通信 vs 充电 功率划分 | [0,1] | C11 |

**离散→连续处理**（关键技巧，式3-36）：信道选择用连续松弛 ε_m(t)∈[0,1]，
`k_m(t) = ⌈ε_m(t)·K⌉`, `p_mk(t)=I{k=k_m(t)}`。→ 整个动作变纯连续。

**归一化动作**（式3-37）：`â^m_t = { l̂, ∂̂, ε̂, β̂, ρ̂ } ∈ [-1,1]^5`，映射（式3-38~3-42）：
- l_m = (l̂+1)/2 · l^max
- ∂_m = π·∂̂ + π ∈ [0,2π)
- ε_m = (ε̂+1)/2 ∈ [0,1]
- β_m = (β̂+1)/2 ∈ [0,1]
- ρ_m = (ρ̂+1)/2 ∈ [0,1]

---

## 2. 状态空间 / 局部观测（式3-43~3-48）

**局部观测**（式3-43，8 维）——执行期每架无人机只能看到：
`o^m_t = { x_m(t), y_m(t), E^rem_m(t), l_m(t-1), ∂_m(t-1), ε_m(t-1), β_m(t-1), ρ_m(t-1) }`
= 当前位置 + 剩余能量 + **上一时隙动作**（提供时序可辨识性）。

**归一化观测**（式3-44~3-47）：位置除以 X^max/Y^max，能量除以 E^init。

**全局状态**（式3-48）：所有无人机局部观测拼接
`s_t = { ō^m_t | m ∈ M }`。

**CTDE 分工**：训练期 Critic 用 s_t + 联合动作评估价值；执行期 Actor 仅用 o^m_t 出动作。

## 3. 奖励函数（式3-49、3-50）

`r^m_t = λ1·Σ_n Z_mn(t) + λ2·E_charge(t) − λ3·e_m(t) − λ4·Ξ_m(t)`, λ≥0。

- 第①项 **探测奖励**：鼓励更多有效探测（Z_mn 见下）。
- 第②项 **充电奖励**：当前时隙融合基站能量收集增量 E_charge。
- 第③项 **能耗代价**：抑制高能耗机动。
- 第④项 **违规惩罚** Ξ_m（式3-50）：
  `Ξ_m(t) = ξ_B·Z^B_m(t) + ξ_C·Σ_{m'≠m} Z^C_mm'(t) + ξ_E·Z^E_m(t)`
  = 出界 + 碰撞/过近 + 能量预留违反。

> 结构 = "正向收益（探测+充电）− 负向代价（能耗）− 违规惩罚"。这与全局优化目标（式3-33）线性组合结构一致，是奖励=目标分解的体现。**迁移到边缘卸载时可直接套这个模板。**

---

## 4. 优化目标（全局，式3-33）——奖励就是它按智能体的分解

```
max_{l,∂,p,β,ρ}  (1/T) Σ_{t=1}^{T} [ ω1·Σ_n q_n(t)      (探测次数总和)
                                     + ω2·g_t            (探测公平, Jain)
                                     + ω3·g_e(t)         (能耗公平, Jain)
                                     + ω4·E_charge(t)    (充电收集)
                                     − ω5·Σ_m e_m(t) ]   (能耗)
```
ω1..ω5 > 0 为权重。

**约束 C1–C14**：
- C1,C2 边界；C3 防碰撞 d_mm'≥d^safe；
- C4 雷达 SINR η_mn≥η^min；C5 通信速率 R_m≥R^min；
- C6 每机占一个信道 Σ_k p_mk=1；C7 每信道≤一机；C12 p_mk∈{0,1}；
- C8 方向∈[0,2π)；C9 距离∈[0,l^max]；C10 β∈[0,1]；C11 ρ∈[0,1]；
- C13 无人机能量预留 E^rem_m≥E^reserve；C14 基站储能 0≤E^FC≤E^FC_max。

---

## 5. 关键中间变量（连接动作与目标）

- **有效探测** Z_mn(t)∈{0,1}（式3-26）：R_m(t)≥R^min 且 η_mn(t)≥η^min 时为 1。
- q_n(t)=Σ_m Z_mn(t) 目标 n 的有效探测次数（式3-27）；q̄_n 平均（式3-28）。
- 探测公平 g_t（Jain，式3-29）；能耗公平 g_e（式3-31）；充电均衡 g_c（式3-32，正文定义但3-33最终用 E_charge）。

## 6. 底层系统模型变量（喂进上面这些量）

- **运动学**（3.1）：位置累加 (3-1)；边界/碰撞约束。
- **通信链路**（3.2.1）：LoS 概率(3-8)、路损(3-9)、信道增益 Ω(3-10)、SINR ψ(3-11)、速率 R(3-12)。功率两级划分：β 分主/副波束，ρ 分主波束内 通信/充电。
- **能量收集**（3.2.1）：基站接收 RF 功率 P_rx(3-14)→ Sigmoid 整流(3-15)→ 直流 P_EH → E_charge=Σ_m P_EH·τ。
- **雷达探测**（3.2.2）：SINR η_mn(3-16)、同频干扰(3-17)、CRLB(3-18)。
- **能量动态**（3.3）：飞行功率 P(v)(3-20)、能耗 e_m=P·τ(3-21)、无人机剩余能量 E^rem(3-24)、基站储能 E^FC 更新(3-23)。

**三句话总结**：
1. 算法层不动——扩散策略 + MAPPO + CTDE 整套照搬，只换"环境"。
2. 环境层替换——把无人机的 动作/状态/奖励 换成卸载问题的（状态/奖励已在 env 建好）。
3. 两个待定——智能体粒度（每卡 or 中央）与动作定义（卸载时刻 or 再加任务路由），取决于
   "多 GPU = layer→GPU 还是 task→GPU"（见 `系统建模-代码说明.md` 第五节）；
   离散选择可复用毕设的"连续松弛"技巧。
