## 1. 怎么量的（为什么可信）

两把尺子，**都不靠"每页多少词"这种拍脑袋常数**：

**① 几何尺（只对 TJCCT 用）**——直接在 PDF 上量"第 3 章标题"到"第 4 章标题"之间占了多少**栏**。
1 栏 = 半页，所以栏数 ÷ 2 = 页数。**这是唯一零假设的度量。**

```
第 3 章起点: p4 左栏 y=407     第 4 章起点: p7 右栏 y=355
⇒ 6.92 栏单位 = 3.46 个 IEEE 双栏页
```

**② 词数尺（两边都用）**——我们的稿子是 A4 单栏导出，几何尺量不出 IEEE 页数，只能换算。
换算系数**不是猜的，是从 TJCCT 自己的 14 个小节最小二乘回归出来的**：

```
367 正文词 / 栏单位  =  733 正文词 / 页        逐小节最大残差 0.21 栏单位（≈11% 页）
```

这个密度（733 词/页）比"满页纯文字 1050 词"低，因为**它已经把 TJCCT 的公式占位摊进去了**。
我们的公式密度（1/103 词）略高于 TJCCT（1/123 词），所以换算结果**偏保守**——真实页数可能再多一点点。

**"正文词"的定义**：过滤掉数学 token 后剩下的词。剔除规则 = 不含字母、字母数 < 2（单字母 = 数学符号）、
含非 ASCII（希腊字母）、含 `= \ ^ _ { } [ ] < > |`。两边用同一套规则。
